Steerpast IAM is a security control plane for human and AI-agent access. It connects identity context, risk, policy evaluation, Claude-assisted decisioning, remediation, and audit evidence in one workflow.

Explore the live demo

How Steerpast works

  1. Observe identity and entitlement context.
  2. Assess privilege, sensitivity, and behavioral risk.
  3. Evaluate policy constraints and eligibility.
  4. Decide with a model-assisted decision layer when Claude is configured.
  5. Act through review, revocation, or another controlled remediation path.

Claude integration

DecisionAgent is the Claude integration point. Deterministic risk and policy signals are assembled first. Claude can then return a supported outcome, rationale, and confidence. The response is validated before it enters the remediation workflow, and failed model calls fall back to deterministic heuristics.

Security posture

The public demo uses sample data and does not require a customer identity-provider connection. API credentials are server-side environment variables. Model output is validated, and sensitive remediation remains operator-controlled.
